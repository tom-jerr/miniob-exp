1. 总体分层架构

End-to-End Architecture

MiniOB 的 SQL 执行层、事务管理层与 LSM 存储引擎通过清晰接口解耦：SQL 解析与算子层负责语法、表达式求值与标量/分组聚合；LsmTableEngine 与 LsmMvccTrx 将关系表 CRUD 与二级索引点查接入 ObLsmTransaction；底层 ObLsmImpl 提供可插拔 MemTable、WAL 持久化、Block Cache、SSTable 与 Leveled Compaction。

2. LAB#1 LSM-Tree 核心实现

Storage Kernel

任务 1：SkipList 无锁并发写入

  • 实现 find_greater_or_equal，自顶向下定位每层前驱节点数组 prev[]；
  • insert 用于单写者路径；insert_concurrently 使用 thread_local 随机数生成器避免跨线程伪共享，并自底向上逐层执行 compare_exchange_strong（CAS），失败时在当前层重新推进前驱节点再重试；
  • seq/acquire-release 内存序保证并发读者无需加锁即可安全遍历。

任务 2：Block Cache 与 SSTable 读写

  • ObLRUCache 采用双向链表 + 哈希表 + 互斥锁，实现线程安全 O(1) get/put；
  • ObBlock::decode 按小端长度前缀解码 KV 与重启点元数据；
  • ObSSTable::init 读取 Footer 还原 Index Block，read_block_with_cache 先查 (sst_id, block_offset) 缓存，未命中再 pread 回填。

任务 3：Leveled Compaction 流程

STEP 1 · PICK
范围选盘 LeveledCompactionPicker::pick 优先检查 L0 文件数是否超阈，否则选最大字节溢出层 L_i；计算 [min_user_key, max_user_key] 并选出 L_{i+1} 重叠 SSTables。
STEP 2 · MERGE
多路归并去重 do_compaction 构造多路归并迭代器，保留相同 user_key 的最新 seq（若所有快照都不再需要旧版本且无更低层数据，清理墓碑）。
STEP 3 · BUILD
流式落盘 通过 ObSSTableBuilder（open/add/finish）按目标 table_size 切分生成新 SSTable，直接写入 L_{i+1}。
STEP 4 · SWITCH
原子切换与回收 持久化 ObManifest，持锁切换版本列表；旧 SSTable 仅执行 POSIX unlink，由并发读线程的 shared_ptr RAII 安全关闭 fd。

3. 可插拔 MemTable（SkipList / 并发 B+Tree）

ObMemBPlusTree

通过 ObLsmOptions::memtable_type（MemTableType::SKIPLIST / MemTableType::BPLUS_TREE）在运行期无感切换内存索引结构，二者向上暴露完全统一的 ObMemTable::new_iterator() 接口并刷写为完全一致的磁盘 SSTable 格式。

  • 并发控制：ObMemBPlusTree 使用节点/树级 std::shared_mutex（读共享、写独占），支持节点自动分裂与根节点上升；
  • 抗游标漂移迭代器：ObMemBPlusTree::Iterator 缓存上一次返回的 current_key_。在两次调用间隙若写线程向同一叶子插入更小键导致数组右移，next() 重新持锁后校验偏移并自动回退至 std::upper_bound(current_key_) 重定位，严格保证扫描单调不重复。

4. LSM MVCC / OCC 事务引擎与 Spill-to-Disk

Concurrency & Scalability

4.1 快照版本与隔离级别控制

机制维度 默认：Snapshot Isolation (SI) 可选：Serializable
快照水位 开启事务时读取 ts_ = seq_.load()（1-based 分配，保证空库 ts_=0 不越界） 同左
写集缓存 未提交写暂存 inner_store_（读己之写优先命中写集） 同左 + read_set_ / scan_ranges_ 记录读轨迹
提交校验 (OCC) 在 commit_mtx_ 临界区检查写集中每个键的最新提交序号是否 > ts_（First-Committer-Wins，消除 Lost Update） 额外校验 read_set_ 与区间扫描范围内是否有并发提交更新（消除 Write Skew）
原子持久化 ObLsmImpl::batch_put 先写整体 WAL 批次，再统一分配新 seq 写入 MemTable 同左

4.2 大事务 Spill-to-Disk WriteBatch 与二级索引协同

Spill-to-Disk 溢出流程

  1. 当事务写集字节数超过 max_write_batch_size，将当前 inner_store_ 流式刷写为临时 trx_{uid}_spill_{idx}.sst 并清空内存表；
  2. get() / TrxIterator 按「Active 内存写集 → 逆序 Spill SSTables → DB Snapshot」三级归并读取；
  3. commit() 时通过 MultiLevelWriteBatchIterator 分块流式调用 batch_put 落盘，提交/回滚/析构时自动清理所有临时 Spill 文件。

LsmTableEngine & 二级索引

  1. LsmSecondaryIndex::get_record(key, rid, trx) 接收 Trx * 参数，经由 LsmMvccTrx 的 ObLsmTransaction::get() 读取主表快照，不可见则返回 RC::RECORD_INVISIBLE；
  2. IndexScanPhysicalOperator 遇到 RECORD_INVISIBLE 自动跳过；
  3. LsmTableEngine::update_record_with_trx 支持 LSM MVCC UPDATE：保留旧二级索引条目供历史快照回表，更新非索引列时忽略同键 RECORD_DUPLICATE_KEY。

5. SQL 聚合函数与负数字面量解析

SQL Frontend & Executor
  • 语法扩展（0 Bison 冲突）：在 yacc_sql.y 增加 ID LBRACE expression RBRACE 与 ID LBRACE RBRACE 解析聚合调用；新增独立非终结符 signed_value（支持 value | '-' NUMBER | '-' FLOAT）用于 INSERT、UPDATE、WHERE 与 SET，避免与表达式一元负号 '-' expression %prec UMINUS 冲突。
  • 全量聚合算子：在 aggregator.h/.cpp 与 expression.cpp 实现 NULL-safe 的 MIN、MAX、COUNT、SUM、AVG，正确推导 COUNT(*)->INTS 与 AVG->FLOATS；
  • 空表标量聚合：ScalarGroupByPhysicalOperator 在子算子返回 0 行时仍初始化空分组产出 1 行（COUNT(*)=0，其余为 UNDEFINED 并在 Value::to_string() 输出 "NULL"）。

6. Pre-Commit 门禁与 TPC-C 自测体系

Quality & Benchmark

本地日常提交通过 tools/pre_commit_check.sh 执行快速静态与并发门禁（约 1 分钟）；全量 LSM MVCC 4 线程 TPC-C 压测与磁盘长压测按需在自测阶段显式开启。

# 1. TPC-C 4 线程并发性能 LSM MVCC 自测命令（400 事务，验证 CC1~CC6）
python3 test/tpcc/miniob_tpcc.py \
  --observer "$(pwd)/build_release/bin/observer" \
  --engine lsm --trx lsm --threads 4 --transactions 400 --seed 42

# 2. 完整自测模式（含全量 CTest + MVCC 并发测试 + TPC-C 1T/4T 基线回归校验）
RUN_TPCC=1 TPCC_FAIL_ON_REGRESSION=1 CTEST_EXCLUDE=memtracer_test bash tools/pre_commit_check.sh
